# 우리 가족 비상연락

전쟁, 자연재해, 전염병 같은 비상 상황에서 가족이 서로의 안전을 확인하고 다시 모이기 위한 웹사이트입니다.
휴대폰으로 열어 **"나 무사해요"** 버튼 하나로 생존신고를 하고, 미리 정한 집합장소로 모입니다.

- 화면: GitHub Pages (무료)
- 데이터·로그인: Firebase 무료 요금제(Spark)
- 비상 알림·관리자 작업: Cloudflare Workers 무료

설계와 결정 사항은 [docs/design.md](docs/design.md)에 있습니다.

## 기능

| 기능 | 누가 |
|---|---|
| 접속 코드 3가지(가족·관리자·백업)로 들어와 이름 고르기 (한 번 들어오면 유지) | 가족 모두 |
| 한국어 / English 전환 | 가족 모두 |
| "나 무사해요" / "도움 요청" 생존신고 (GPS 위치 + 시간 기록) | 가족 모두 |
| 현재 위치 확인, 실시간 추적, 체크포인트 저장 (오프라인에서도 GPS 동작) | 가족 모두 |
| 집합장소까지 거리·방향·도보 시간 (지도 없이도 표시) | 가족 모두 |
| 문자로 알리기 (데이터가 끊기고 문자만 될 때) | 가족 모두 |
| 집합장소 1~10순위, 진행 단계, 지금 갈 곳과 남은 시간, 길찾기, 집합장소 게시판 | 가족 모두 |
| 상황별 대처법 15가지 (핵심 요약, 단계별 행동, 준비 체크리스트) | 가족 모두 |
| 비상 연락처 (공공 번호 + 가족 지정 연락처), 사용 안내 | 가족 모두 |
| 비상 2단계: 2급(준위험, 알림만) → 1급(지진·전쟁·대형재난, 경보음 + 알림) | 관리자 (무제한), 일반 가족 (선언권 1회) |
| 빠른 비상 선언: 홈·비상 경보 화면에서 상황 버튼 한 번 + 확인 | 관리자 |
| 관리자 설정 한 화면: 비상 선언·격상·해제, 가족 확인 현황, 소리·알림 테스트, 가족 등록·선언권 관리, 설정 바로가기 | 관리자 |
| 경보 화면·확인 창은 화면 정중앙 | 가족 모두 |
| 경보 대기 모드: 앱을 열어 둔 채 화면이 꺼져도 1급 경보음 (휴대폰마다 켜기) | 가족 모두 |
| 테스트 알람 받을 사람 고르기 | 관리자 |
| 안드로이드 앱: 1급 비상은 화면이 꺼져 있거나 앱이 닫혀 있어도 잠금 화면 위 전체 화면 경보 + 경보음 | 가족 모두 (안드로이드) |
| 가족 전체 테스트 알람 1급·2급 (누가 확인했는지 표시), 이 휴대폰 경보음 시험 | 관리자 / 가족 모두 |
| 가족 추가·수정·삭제, 볼 수 있는 가족 지정, 접속 코드 바꾸기 | 관리자 |
| 관리자 기록: 비상·알림 발송 결과·생존신고·집합 기록·관리 작업을 한 화면에 (필터, CSV) | 관리자 |
| 가족 정보 한눈에: 모든 가족의 개인정보·대비 상태 표 (CSV) | 관리자 |
| 집합장소·대처법·연락처 편집 | 관리자 |
| 인쇄용 비상카드, 글자 크기 조절 | 가족 모두 |
| 오프라인 동작 + 오프라인 준비 점검 (저장 공간 고정, 집합장소 지도 미리 받기, 위치 권한) | 가족 모두 |

화면은 미국 정부 웹 디자인 시스템(USWDS)의 디자인 원칙(배색, 알림 상자, 단계 표시, 표)을 참고했습니다.

### 누가 무엇을 볼 수 있나

관리자는 가족 전체를 봅니다. 일반 가족은 **본인과, 관리자가 지정한 최대 3명**만 봅니다 (서버 규칙이 강제).

| 정보 | 본인 | 지정된 가족 (최대 3명) | 그 밖의 가족 | 관리자 |
|---|---|---|---|---|
| 이름, 전화번호, 마지막 생존신고(상태·시간·위치) | ✅ | ✅ | ❌ | ✅ |
| 성별, 나이, 혈액형, 의료 메모, 비상연락처, 주소, 이메일 | ✅ | ✅ | ❌ | ✅ |
| 전체 위치 기록, 체크리스트 진행 | ✅ | ❌ | ❌ | ✅ |
| 집합장소 게시판 글 | ✅ | ✅ | ✅ | ✅ |
| 관리자 기록 | ❌ | ❌ | ❌ | ✅ |

## 설치 순서

처음 한 번만 하면 됩니다. 30~40분 정도 걸립니다.

### 1. Firebase 프로젝트 만들기

1. <https://console.firebase.google.com> 에서 **프로젝트 추가**. Google 애널리틱스는 꺼도 됩니다.
2. **빌드 → Authentication → 시작하기 → 로그인 방법 → 이메일/비밀번호** 사용 설정.
3. **빌드 → Firestore Database → 데이터베이스 만들기**
   - 위치: `asia-northeast3 (서울)`
   - **프로덕션 모드**로 시작
4. **보안 규칙 올리기** — 둘 중 하나:
   - 콘솔: Firestore → 규칙 탭에 [firestore.rules](firestore.rules) 내용을 통째로 붙여 넣고 게시. 색인 탭에서 `checkins` 컬렉션에 `uid 오름차순, clientAt 내림차순` 복합 색인 추가.
   - 명령어: `npx firebase-tools login` 후 `npx firebase-tools deploy --only firestore --project 내프로젝트id`
5. **프로젝트 설정(톱니바퀴) → 일반 → 내 앱 → 웹(</>) 앱 추가**. 나온 `firebaseConfig` 값을 [web/js/config.js](web/js/config.js)의 `firebase` 에 넣습니다. 이 값은 공개돼도 괜찮습니다.
6. **프로젝트 설정 → 클라우드 메시징 → 웹 구성 → 웹 푸시 인증서 → 키 쌍 생성**. 나온 키를 `config.js`의 `vapidKey` 에 넣습니다.
7. **Authentication → 설정 → 승인된 도메인**에 `devmh1003.github.io` 추가.

### 2. Cloudflare Worker (알림 서버)

1. **서비스 계정 키 만들기**: Firebase 프로젝트 설정 → 서비스 계정 → **새 비공개 키 생성** → JSON 파일 다운로드.
   - 이 파일은 비밀번호와 같습니다. 저장소에 절대 올리지 말고, Worker에 등록한 뒤 지우세요.
   - 권한을 줄이려면 [Google Cloud IAM](https://console.cloud.google.com/iam-admin/iam)에서 이 서비스 계정의 역할을 `Cloud Datastore 사용자`, `Firebase Cloud Messaging API 관리자`, `Firebase 인증 관리자` 세 개로 바꿉니다.
2. <https://dash.cloudflare.com> 가입 (무료, 카드 불필요).
3. [worker/wrangler.toml](worker/wrangler.toml)의 `FIREBASE_PROJECT_ID` 를 내 프로젝트 id로 바꿉니다.
4. 터미널에서:
   ```bash
   cd worker
   npm install
   npx wrangler login
   npx wrangler secret put GOOGLE_SERVICE_ACCOUNT
   ```
   마지막 명령에서 서비스 계정 JSON 파일 내용을 통째로 붙여 넣습니다. 그다음:
   ```bash
   npx wrangler deploy
   ```
5. 나온 주소(`https://family-emergency.○○○.workers.dev`)를 `config.js`의 `workerUrl` 에 넣습니다.

### 3. GitHub Pages

1. 저장소 **Settings → Pages → Build and deployment → Source: GitHub Actions**.
2. `config.js` 변경을 `main` 에 올리면 자동으로 배포됩니다. 주소: <https://devmh1003.github.io/emergency/>

### 4. 처음 설정 (배포 직후 바로)

1. 사이트를 열면 **처음 설정** 화면이 나옵니다 (아직 설정 전일 때만).
2. 첫 관리자 이름·전화번호와 **접속 코드 3가지**를 정합니다.
   - **가족 코드** (6자 이상): 일반 가족이 들어올 때.
   - **관리자 코드** (8자 이상): 관리자가 들어올 때.
   - **백업 코드** (8자 이상): 관리자 코드를 잊었을 때. 종이에 적어 안전한 곳에 보관합니다.
   - 세 코드는 서로 달라야 하고, 어디에도 저장되지 않아 다시 볼 수 없습니다.
3. 설정을 마치면 이 화면은 닫히고, 예전 방식(아이디·비밀코드)으로 만든 계정은 더 이상 들어올 수 없습니다.
4. 혹시 내가 아닌 사람이 먼저 설정했다면: Firestore 콘솔에서 `public/gates` 문서를 지우고 다시 하세요.

### 5. 마무리 (권장)

- **API 키 제한**: [Google Cloud 사용자 인증 정보](https://console.cloud.google.com/apis/credentials)에서 "Browser key"를 열고 **웹사이트 제한**에 `https://devmh1003.github.io/*` 추가 (로컬 개발 시 `http://localhost:5500/*` 도).
- **가족 추가**: 가족 탭 → `+ 가족 추가`. 이름만 정하면 됩니다(아이디·비밀번호 없음). **볼 수 있는 가족**을 최대 3명 지정하고, 가족 코드를 알려 줍니다.
- **접속 코드 바꾸기**: 설정 → 접속 코드 관리. 예전 코드를 몰라도 바꿀 수 있습니다. 관리자 코드를 잊었다면 백업 코드로 들어와 바꿉니다.
- **집합장소 정하기**: 가족 탭 → 관리자 메뉴 → 집합장소 설정.
- **대처법 불러오기**: 가족 탭 → 관리자 메뉴 → 대처법 관리 → 기본 프로토콜 불러오기 (수정하고 싶을 때만).

## 가족에게 알려 줄 것

1. 휴대폰으로 사이트를 열고 **가족 코드**를 넣은 뒤 내 이름을 고릅니다. (영어가 편하면 오른쪽 위 **English**)
2. **홈 화면에 추가** (아이폰은 Safari 공유 버튼 → 홈 화면에 추가). 그래야 알림이 오고 인터넷 없이도 열립니다.
3. 홈 화면 아이콘으로 열어 **설정 → 알림 켜기 → 테스트 알림**, 그리고 **설정 → 오프라인 준비 → 지금 준비하기** (집합장소 지도를 받고 위치 권한을 미리 허용).
4. **설정 → 인쇄용 비상카드**를 출력해 지갑과 배낭에.
5. 비상 시: 열자마자 **"나 무사해요"**. 연락이 안 돼도 **1순위 집합장소**로.

## 업데이트할 때 주의

[firestore.rules](firestore.rules)가 바뀐 버전을 올릴 때는 **사이트를 올리기 전에 규칙부터 Firebase 콘솔에 다시 게시**하세요. 화면이 새 규칙을 전제로 동작하기 때문에, 순서가 바뀌면 일부 저장이 거부됩니다.

## 비상 시 안정성

- 화면은 GitHub(전 세계 CDN), 데이터는 Google, 알림은 Cloudflare로 나뉘어 있습니다.
- 한 번 열어 본 휴대폰은 앱 화면, 대처법(한국어·영어), 집합장소, 가족 연락처를 저장해 둡니다.
- 들어오면 자동으로(하루 한 번, 집합장소가 바뀔 때도) 집합장소와 내 위치 주변 지도를 미리 받고, 브라우저가 저장본을 지우지 않도록 저장 공간 고정을 요청합니다. **설정 → 오프라인 준비**에서 상태를 확인할 수 있습니다.
- 인터넷 없이 누른 생존신고는 휴대폰에 보관됐다가 연결되면 자동 전송됩니다.
- GPS는 인터넷 없이도 동작합니다. 첫 위치를 잡는 데 시간이 더 걸릴 수 있어 오프라인에서는 최대 1분 기다리고, 마지막으로 잡힌 위치를 휴대폰에 저장해 둡니다. 지도가 안 떠도 집합장소까지의 거리와 방향을 보여줍니다.
- 데이터는 끊기고 문자만 될 때: **문자로 알리기** 버튼.
- 휴대폰이 꺼졌을 때: **인쇄용 비상카드**.

## 보안

[SECURITY.md](SECURITY.md)를 참고하세요. 요약:

- 모든 권한은 서버(Firestore 보안 규칙)에서 검사합니다. 화면 코드를 고쳐도 남의 정보를 볼 수 없습니다.
- 접속 코드를 모르면 들어올 수 없습니다. 코드를 알아도 관리자가 등록한 이름으로만 들어오고, 볼 수 있는 범위는 서버 규칙이 정합니다.
- 비밀 키는 Cloudflare 비밀 변수에만 있고, 저장소에는 없습니다.
- GitHub CodeQL, Dependabot, 비밀 스캔, OpenSSF Scorecard로 자동 점검합니다.

## 안드로이드 앱 (`android/`)

사이트를 그대로 여는 안드로이드 앱입니다. 사이트를 고치면 앱에도 바로 반영되므로, 앱은 알림·권한 부분을 바꿀 때만 다시 빌드합니다.

- 1급 비상(과 1급 테스트 알람): 화면이 꺼져 있거나 앱이 닫혀 있어도 잠금 화면 위에 전체 화면 경보가 뜨고, 확인할 때까지 알람 소리로 경보음이 울립니다.
- 2급 비상·해제·테스트 알림: 보통 알림.
- 처음 실행하면 권한 화면이 뜹니다: 알림, 전체 화면 알림, 방해 금지 무시, 배터리 최적화 제외, 위치. 사이트의 설정 → 📱 앱 경보 권한에서 다시 열 수 있습니다.
- 알림 서버는 앱이 등록한 기기(사용자 에이전트에 `FamilyEmergencyApp`)에는 데이터 메시지를 보냅니다.

빌드 (JDK 17, Android SDK 35):

```bash
cd android
gradle assembleRelease   # app/build/outputs/apk/release/app-release.apk
```

- `android/local.properties` 에 `sdk.dir=...`, `android/keystore.properties` 에 서명 키 정보(storeFile, storePassword, keyAlias, keyPassword)를 둡니다. 둘 다 저장소에 올리지 않습니다.
- **서명 키를 잃어버리면 앱을 업데이트할 수 없습니다** (지우고 다시 설치해야 함). 키 파일과 비밀번호를 따로 백업하세요.
- 배포: GitHub Releases 에 `family-emergency.apk` 로 올리면, 안드로이드 휴대폰의 설정 화면에 받기 링크가 보입니다.
