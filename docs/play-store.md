# 구글 플레이 등록 안내 (가족만: 내부 테스트)

가족만 설치하는 **내부 테스트** 트랙으로 올립니다. 초대한 가족의 구글 계정만 플레이 스토어 링크로 설치할 수 있고, 검색에는 나오지 않습니다. 플레이 프로텍트 차단 경고 없이 설치되고 자동으로 업데이트됩니다.

준비된 파일:

| 파일 | 쓰는 곳 |
|---|---|
| `%LOCALAPPDATA%\FamilyEmergencyBuild\release\family-emergency-1.1.aab` | 앱 번들 (업로드) |
| `android/store/icon-512.png` | 앱 아이콘 |
| `android/store/feature-1024x500.png` | 그래픽 이미지 |
| `android/store/screenshot-1-home.png`, `-2-admin.png`, `-3-alarm.png` | 휴대전화 스크린샷 |
| https://devmh1003.github.io/emergency/privacy.html | 개인정보처리방침 URL |

## 1. 개발자 계정 만들기 (직접)

1. https://play.google.com/console/signup 에 들어가 **개인** 계정을 고릅니다.
2. 등록비 25달러를 결제하고, 신분증·전화번호 본인 확인을 합니다. 확인에 며칠 걸릴 수 있습니다.
3. 안드로이드 휴대폰으로 기기 확인을 하라고 하면 안내에 따라 "Play Console" 앱으로 확인합니다.

## 2. 앱 만들기

Play Console → **앱 만들기**

- 앱 이름: `우리 가족 비상연락`
- 기본 언어: 한국어
- 앱 또는 게임: 앱 / 무료 또는 유료: 무료
- 개발자 프로그램 정책·미국 수출법 동의 (직접 확인 후 체크)

## 3. 내부 테스트 출시

**테스트 및 출시 → 테스트 → 내부 테스트**

1. **테스터** 탭 → 이메일 목록 만들기 → 가족의 구글 계정(플레이 스토어에 로그인한 계정) 이메일을 넣습니다.
2. **새 버전 만들기** → 앱 서명: **Google Play 앱 서명** 사용(기본값) → `family-emergency-1.1.aab` 업로드.
   - 우리 서명 키는 "업로드 키"가 됩니다. 다음 버전도 같은 키로 서명해야 하니 키를 꼭 백업하세요.
3. 출시 이름 `1.1`, 출시 노트 예: `1급 비상 전체 화면 경보, 권한 설정 화면`.
4. **저장 → 검토 → 내부 테스트로 출시 시작**.
5. **테스터** 탭의 **링크 복사**(참여 링크)를 가족에게 보냅니다. 가족은 링크에서 "테스터 되기" → 플레이 스토어에서 설치.

> GitHub에서 받은 앱이 이미 깔려 있으면 서명이 달라 업데이트가 안 됩니다. **먼저 지우고** 플레이 스토어에서 설치하세요.

## 5. 스토어 등록정보 (기본 스토어 등록정보)

- 앱 이름: `우리 가족 비상연락`
- 간단한 설명 (80자): `가족 비상 경보·생존신고·집합장소 안내. 1급 비상은 잠금 화면 위 전체 화면 경보.`
- 자세한 설명:

```
우리 가족만 쓰는 비상연락 앱입니다. 가족 관리자가 정한 접속 코드로만 들어올 수 있습니다.

■ 비상 경보 2단계
· 1급 비상(지진·전쟁·대형재난): 화면이 꺼져 있거나 앱이 닫혀 있어도 잠금 화면 위에 전체 화면 경보가 뜨고, 확인할 때까지 경보음이 울립니다.
· 2급 비상(준위험): 알림만 갑니다.
· 관리자는 상황 버튼 한 번으로 바로 선언하고, 격상·해제할 수 있습니다.

■ 생존신고와 가족 현황
· "나 무사해요" 버튼 하나로 위치와 시간을 가족에게 알립니다.
· 가족 모두의 무사·도움 필요·확인 안 됨 상태를 한눈에 봅니다.

■ 집합장소
· 1~10순위 집합장소와 도착 시간, 거리·방향을 안내합니다. 인터넷이 없어도 저장된 정보와 GPS로 동작합니다.

■ 대처법과 연락처
· 전쟁·지진·홍수 등 15가지 상황별 대처법과 대비 체크리스트, 비상 연락처.

■ 테스트 알람
· 관리자가 고른 가족에게 1급·2급 테스트 알람을 보내고, 누가 확인했는지 봅니다.

한국어·English 지원.
```

- 앱 아이콘: `android/store/icon-512.png`
- 그래픽 이미지: `android/store/feature-1024x500.png`
- 휴대전화 스크린샷: `android/store/screenshot-1-home.png`, `screenshot-2-admin.png`, `screenshot-3-alarm.png` (가짜 가족 이름으로 찍은 화면)
- 앱 카테고리: 도구(또는 생활), 연락처 이메일: 개발자 계정 이메일

## 6. 다음 버전 올리기

1. `android/app/build.gradle` 의 `versionCode` 를 1 올리고 `versionName` 을 바꿉니다.
2. 빌드 (Windows, `%LOCALAPPDATA%\FamilyEmergencyBuild` 의 JDK 17·SDK·Gradle 8.13):
   - 이 컴퓨터에서는 Java 임시 폴더 문제 때문에 `JAVA_TOOL_OPTIONS=-Djdk.net.unixdomain.tmpdir=<없는 폴더>` 를 붙여야 빌드됩니다.
   - `gradle bundleRelease` → `app/build/outputs/bundle/release/app-release.aab`
3. 내부 테스트 → 새 버전 만들기 → 업로드 → 출시.

사이트(화면·기능)는 앱이 그대로 열어 보여 주므로, 사이트만 고칠 때는 앱을 다시 올릴 필요가 없습니다.
